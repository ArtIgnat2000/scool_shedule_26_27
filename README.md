# 📚 Школьное расписание · v2.1.0

Расписание уроков для 2«В» и 4«Б», календарь каникул, питание и персональные страницы учеников.
Все данные загружаются динамически из файлов каталога `data/` — расписание меняется
редактированием JSON-файлов, без правки кода.

## Страницы

| Страница | Что показывает |
|---|---|
| `index.html` | Расписание уроков с переключателями класса и системы обучения, автоматическим днём, статусом дня и подсветкой текущего/следующего урока; прямая ссылка: `index.html?class=4b` |
| `holidays.html` | Календарь учебного года 2026/2027 (1 сентября 2026 — 31 мая 2027) по месяцам: учебные дни — чёрным на белом, выходные и праздники — красным, каникулы — на зелёном фоне, «сегодня» — выделено; есть счётчик до каникул и переход по клику на период |
| `student.html` | Список учеников; `student.html?id=artem-2v` — личная страница: уроки класса + доп. занятия, тренировки и секции, включая Сб и Вс |
| `settings.html` | Отдельная страница настроек: выбор класса и системы «по четвертям / по триместрам» |
| `meal.html` | Расписание завтраков, обедов и полдника только для выбранного класса |

## Структура данных

```
data/
├── classes.json        # список классов и файл по умолчанию
├── class-2v.json       # расписание 2«В» (дни mon..fri → уроки)
├── class-4b.json       # расписание 4«Б»
├── holidays.json       # каникулы, праздники, системы «четверти/триместры»
├── meal.json           # расписание питания и режим работы кафе
└── students/
    ├── index.json      # список учеников
    └── <id>.json       # личные занятия ученика (mon..sun)
```

### Как изменить расписание уроков

Откройте `data/class-2v.json` (или `class-4b.json`) и поправьте нужный урок:

```json
{ "n": 1, "time": "8:30–9:10", "subject": "Математика", "icon": "🧮" }
```

### Ежедневный режим

На главной странице автоматически открывается текущий будний день. В учебный
день приложение показывает статус дня, подсвечивает текущий урок и помечает
следующий урок. Счётчик до каникул считает только учебные дни внутри учебного года;
дни до 1 сентября в него не входят. На странице каникул цветные карточки
периодов кликабельны: клик прокручивает календарь к нужному месяцу и выделяет
дни периода.

Переключатель «По четвертям / По триместрам» сохраняется в браузере. Даты для
системы «по триместрам» пока демонстрационные и требуют уточнения у школы.

### Как добавить класс

1. Создайте `data/class-XX.json` по образцу существующих.
2. Добавьте запись в `data/classes.json`.

### Как добавить ученика

1. Создайте `data/students/<id>.json` по образцу (дни `mon`…`sun`,
   типы занятий: `sport` — спорт, `lesson` — доп. урок, `club` — кружок).
2. Добавьте запись в `data/students/index.json`.

> ⚠️ Репозиторий публичный: используйте только имена без фамилий.

### Как обновить каникулы (раз в год)

Текущий календарь отображается с 1 сентября 2026 по 31 мая 2027. Для системы
«по четвертям» последний учебный день — 26 мая 2027 года, для системы
«по триместрам» — 31 мая 2027 года. Периоды каникул в файле заданы по
рекомендованному графику для четвертей.

Отредактируйте `data/holidays.json`: границы года (`yearStart`/`yearEnd`),
периоды `vacations`, праздники `publicHolidays` и особые даты `specialDays`.

## Локальный запуск

Данные грузятся через `fetch()`, поэтому нужен HTTP-сервер (двойной клик по
`index.html` не сработает — браузер блокирует `fetch` с `file://`):

```powershell
py -3 -m http.server 8000     # или: python -m http.server 8000
```

Откройте `http://localhost:8000`. На GitHub Pages всё работает из коробки.

Вариант — VS Code Live Server: открыть `index.html` → «Open with Live Server».

## Дизайн

Стиль iOS 26 («liquid glass»): системная типографика, компактная шапка с короткими
названиями разделов, настройки вынесены в отдельную страницу, мобильная навигация
перенесена в нижнюю вкладочную панель, полупрозрачные карточки с blur,
сегмент-контролы и автоматическая тёмная тема (`prefers-color-scheme`).
