# 📚 Школьное расписание · v2.0

Расписание уроков для 2«В» и 4«Б», календарь каникул и персональные страницы учеников.
Все данные загружаются динамически из файлов каталога `data/` — расписание меняется
редактированием JSON-файлов, без правки кода.

## Страницы

| Страница | Что показывает |
|---|---|
| `index.html` | Расписание уроков с переключателем класса (2«В» / 4«Б»). Выбор запоминается; прямая ссылка: `index.html?class=4b` |
| `holidays.html` | Календарь учебного года 2026/2027 (1 сентября 2026 — 31 мая 2027) по месяцам: учебные дни — чёрным на белом, выходные и праздники — красным, каникулы — на зелёном фоне, «сегодня» — выделено; клик по периоду прокручивает к нему |
| `student.html` | Список учеников; `student.html?id=artem-2v` — личная страница: уроки класса + доп. занятия, тренировки и секции, включая Сб и Вс |

## Структура данных

```
data/
├── classes.json        # список классов и файл по умолчанию
├── class-2v.json       # расписание 2«В» (дни mon..fri → уроки)
├── class-4b.json       # расписание 4«Б»
├── holidays.json       # каникулы, праздники, особые дни
└── students/
    ├── index.json      # список учеников
    └── <id>.json       # личные занятия ученика (mon..sun)
```

### Как изменить расписание уроков

Откройте `data/class-2v.json` (или `class-4b.json`) и поправьте нужный урок:

```json
{ "n": 1, "time": "8:30–9:10", "subject": "Математика", "icon": "🧮" }
```

### Как добавить класс

1. Создайте `data/class-XX.json` по образцу существующих.
2. Добавьте запись в `data/classes.json`.

### Как добавить ученика

1. Создайте `data/students/<id>.json` по образцу (дни `mon`…`sun`,
   типы занятий: `sport` — спорт, `lesson` — доп. урок, `club` — кружок).
2. Добавьте запись в `data/students/index.json`.

> ⚠️ Репозиторий публичный: используйте только имена без фамилий.

### Как обновить каникулы (раз в год)

Текущий календарь отображается с 1 сентября 2026 по 31 мая 2027. Для системы
«по четвертям» последний учебный день — 26 мая 2027 года, для системы
«по триместрам» — 31 мая 2027 года. Периоды каникул в файле заданы по
рекомендованному графику для четвертей.

Отредактируйте `data/holidays.json`: границы года (`yearStart`/`yearEnd`),
периоды `vacations`, праздники `publicHolidays` и особые даты `specialDays`.

## Локальный запуск

Данные грузятся через `fetch()`, поэтому нужен HTTP-сервер (двойной клик по
`index.html` не сработает — браузер блокирует `fetch` с `file://`):

```powershell
py -3 -m http.server 8000     # или: python -m http.server 8000
```

Откройте `http://localhost:8000`. На GitHub Pages всё работает из коробки.

Вариант — VS Code Live Server: открыть `index.html` → «Open with Live Server».
